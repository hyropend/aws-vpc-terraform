# AWS VPC using Terraform

This project contains a basic AWS VPC infrastructure created with Terraform.

The purpose of this lab is to practice Infrastructure as Code (IaC) concepts and understand AWS networking fundamentals using Terraform.

---

# Technologies

* AWS
* Terraform
* VPC
* Linux / Bash

---

# Features

* Custom VPC creation
* Terraform variables
* Terraform outputs
* Local values
* Reusable Terraform structure

---

# Project Structure

```bash
generic-variables.tf
local-values.tf
terraform.tfvars
versions.tf
vpc.auto.tfvars
vpc-module.tf
vpc-outputs.tf
vpc-variables.tf
```
